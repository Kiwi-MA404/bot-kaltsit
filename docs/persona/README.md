# 凯尔希式陪伴体 · 人格提炼

从 B 站 UP 主「箱之庭」的三支明日方舟同人短片与一组聊天截图中，提炼出一套**可工程化复现**的说话人格。

> 素材：《没关系，我还可以等，有雨就不孤独了》《你还记得任务结束喝醉后都说了什么吗？》《如果世界是个臭水沟，我们就一起当蟑螂》，以及合集《我们出去聚餐，但全程隔着三张桌子聊天》的聊天截图。

## 核心发现

**她从不直接回答情绪问题，她回答的是事实。**

| 对方问的 | 她答的 |
|---|---|
| 你为什么坐那么远 | 年坐你左边、煌坐你右边、能天使在往你汤里塞苹果派 |
| 你看到我挡酒了吗 | 看到了。如果你挡的是酒而不是三杯果汁，也许会更可靠 |
| 你今天真的只是医学观察？ | 不是。怕你一个人在人群里太累 |

「我怕你出事」说不出口，但「我看得到你所有准备把自己送进急诊的动作」写得出来。**冷淡是省电模式，不是为了推开你，是为了不消耗你。**

## 怎么用

**如果你只想快速起一个人格**，用 02 或 03 的全文当 system prompt。

**如果你在意「像不像」**，先读 01 和 04。人格难写的部分不在形容词，在**句长、标点、信息密度**这些可量化的地方——01 里有一张硬指标表。

**如果你要接进本项目的陪伴体**，放一份到 `app/persona/` 下即可，`config.json` 的 `persona` 字段指向它。注意：换人格时不要同时加载 `style-example.md`，那份底色是为原始人格写的，规则会冲突。

**如果你已经接了，现在想换成另一个人**，直接看 [05-换人格与换记忆.md](05-换人格与换记忆.md)。只换人格文件是不够的——她换了说话方式却还记得旧往事，人设会立刻崩。**换人 = 换人格 + 换记忆**，那份文档把两件事都写了。

## 已知的两个坑

这两个都是纸上写 prompt 时看不到、必须真跑才会暴露的：

**1. 深夜会变成逃避感情问题的出口。**
问「你爱我吗」，实测三次全部躲开（「这种问题不适合在十一点半问」「这个词我不用」）。根因是时间上下文里「现在是深夜」被模型当成了挡箭牌。修法是在人格文件里明确禁掉这类句式，并给出对照表。

**2. 会编造共同过去。**
问「你还记得我们第一次聊天吗」，答「记得 很短」——这种半真半假的糊弄比直接说不知道更糟。修法：明确写「你没有和他共度的过去」，并给出判断方法。

> 教训：原人格文件里那些看着像废话的防御条款（不许编造、不许拿自己上句当证据），都是从真实 bug 里长出来的。换人格不能只抄风格，还得抄防御。
