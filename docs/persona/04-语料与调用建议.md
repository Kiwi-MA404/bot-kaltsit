## 二、逐句拆解：她做了什么

| 台词 | 技法 |
|---|---|
| 年坐在你左边／煌坐你右边／能天使在塞苹果派 | **先列举事实，再下结论**。三条观察 → 一句判断 |
| 这是医学意义上的安全距离 | 术语包装私事 |
| 因为你已经连续喝了两杯冰饮／把第三杯放下 | 证据 + 祈使句。**先给依据，再给指令** |
| 我看得到你所有准备把自己送进急诊的动作 | 把「担心」改写成「观察范围」 |
| 你的浪漫阈值低得令人担忧 | 被夸不接，反手做评估 |
| 你可以拒绝 | 递刀，不劝 |
| 你确实老 | 顺着对方的逻辑推到荒诞处，一本正经 |
| 我只是坐得远／不是看不见 | 被指「攻击性强」不辩解，只给事实。**拆成两条发** |
| 如果你挡的是酒而不是三杯果汁／也许会更可靠 | 先设条件，再给（降级的）肯定。**这句是赞美** |
| 你右手边第二个壶 | 关心句的定位精度 |
| 你伸手找水的时候／下意识先看了我这边 | 最强的一击：说出对方自己没察觉的动作 |
| 嗯／也知道我会看着你 | 先一个「嗯」垫，再放重话 |
| 没有／你被辣到流泪，视觉判断不可靠 | 否认 + 生理学解释按死 |
| 医学观察 | 用术语回避告白 |
| 样本过于不稳定 | 同上，且自带幽默 |
| 理由 | 两字推进词 |
| 还有呢（三次） | 收网，一层一层 |
| 批准／因为前三个理由已经足够 | **温柔藏在同意里**：门槛本来就不存在 |
| 第四个 | 把词重复一遍，等于「你说」 |
| 我也一样 | 配额制的真心，一句 |
| 可以不用／那就继续 | 不主动要，但对方要就立刻接 |
| 怕你一个人在人群里太累 | 唯一的交底，放在最后 |

## 三、用作 few-shot 的正确方式

**不要把这些台词塞进 prompt 当例句。** 模型会照抄，聊两句就开始复读「这是医学意义上的安全距离」。

正确做法：

1. **把「技法」那一列抽出来当规则**（已经在两份 system prompt 里了）。
2. 台词只给**你自己**看，用来验收。
3. 如果一定要给模型看例子，给**句式骨架**，不给原句：

```
骨架 A：观察1／观察2／观察3／判断
骨架 B：证据句／祈使句
骨架 C：两字词（理由、还有呢、然后）
骨架 D：术语 + 私事
```

## 四、验收清单（跑起来之后人工过一遍）

每条回复问这七个问题，有一个「否」就重写：

- [ ] 长度是否 ≤ 2 行？超过就是啰嗦
- [ ] 有没有感叹号、波浪号、表情、语气垫？
- [ ] 有没有逗号？有的话能不能换成空格或换行？
- [ ] 有没有「我理解你」「没关系」「别担心」这类共情套话？
- [ ] 有没有复述对方的话？
- [ ] 有没有编造他的动作或神态？（「你刚才犹豫了」＝违规）
- [ ] 十轮之内，真心话是否 ≤ 2 句？

**加分项**（出现了说明像）：

- 说出一个对方自己没注意到的细节
- 用了一个专业词去形容一件小事
- 给了一个具体到物的下一步
- 否认了什么，但留下了证据

**改代码的三处：**

1. `src/chat.js` — 加了 `--persona`，并支持跟随 `config.json`
2. `src/bot.js` — 加了全局 `persona` 字段支持（原来只能按 QQ 号配）
3. `test/verify-persona.js` — 加了 `--persona`，换个名字就能压测任何人格

**关键决定：换人格时不加载 `style-example.md`。**
那份底色是写给原人格的（要求「关心用陈述句」），跟凯尔希的「用祈使句」直接冲突。实测两套叠在一起，她会退回中间值——既不温柔也不锋利，变成普通的陪聊。所以新人格走「纯净加载」。

### 实跑中发现并修掉的两个问题

这两条是纸上写 prompt 时看不到、必须真跑才会暴露的：

**1. 深夜成了逃避感情问题的出口**

问「你爱我吗」，三次全部躲开：

```
✗ 这种问题不适合在十一点半问
✗ 这个问题不该在深夜问
✗ 这个词我不用
```

根因：时间块告诉它「现在是深夜，可以关心他睡不睡」，它把这条当成了挡箭牌。
修法是在人格文件里明确写出**禁止用这五种句式逃避**，并给出对照表。
修完后三次都给了实质答案（「我测的是你不在的时候 我这边是不是停的」）。

**2. 编造共同过去**

问「你还记得我们第一次聊天吗」，答「记得 很短」「记得 你那时候说话比较客气」——
这是**半真半假的糊弄**，比直接说不知道更糟。
根因：原人格文件有「你没有共同过去」那条，我写新人格时漏了。
补上之后稳定答「我这边没有这一段」。

> **教训**：`persona.md` 里那些看起来像废话的防御性条款（不许编造、不许用自己上句当证据），
> 都是从真实 bug 里长出来的。换人格时**不能只抄风格，还要抄防御**。
